# Flowday

장기 목표를 오늘의 시간표와 집중 실행으로 연결하는 생활 관리 앱입니다.

## 주요 기능

- 하루 시간표 블록 추가, 이동, 완료, 삭제
- 주간 캘린더 드래그 이동
- 3년부터 오늘까지 이어지는 목표 분할
- 아이젠하워 매트릭스
- 뽀모도로 집중 타이머
- 주간 실행 리뷰
- Light, Dim, Dark 테마
- 브라우저 로컬 저장

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

## 프로덕션 빌드

```bash
npm run build
npm start
```
